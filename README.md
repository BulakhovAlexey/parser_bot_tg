## Telegram Bot 🤖

Проект представляет собой [Telegram-бота](https://t.me/ParseGeoChannelsBot), разработанного на базе [Laravel](https://laravel.com) и библиотеки [MadelineProto](https://github.com/danog/MadelineProto) для взаимодействия с Telegram API. Бот позволяет пользователям выбирать канал, вводить нужный адрес и получать уведомления о важных событиях, таких как отключение воды или электричества.

---

## 🚀 Основные возможности

- 🔐 **Авторизация в Telegram** через [MadelineProto](https://github.com/danog/MadelineProto) для доступа к необходимым каналам.
- 🗂️ **Выбор Telegram-чата** для поиска уведомлений.
- 🔎 **Поиск по ключевым словам** (например, улица) в сообщениях выбранных каналов.
- 📢 **Уведомления о событиях** на основе заданных ключевых слов и локации.
- ✅ **Подписка/отписка от уведомлений** с гибкой настройкой.
- ℹ️ **Получение актуальной информации** о текущей подписке.
- 💾 **Сохранение введённых пользователем данных** в базе для последующего анализа и обработки.
