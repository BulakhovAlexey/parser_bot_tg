## Telegram Bot 🤖

Проект представляет собой [Telegram-бота](https://t.me/ParseGeoChannelsBot), разработанного на базе [Laravel](https://laravel.com), библиотеки [MadelineProto](https://github.com/danog/MadelineProto) и [API Telegram](https://core.telegram.org/). Бот позволяет пользователям выбирать чат, вводить нужный адрес и получать уведомления об отключениях воды или электричества по выбранной улице.

### 🚀 Основные возможности

- 📋 **Просмотр доступных Telegram-чатов** где публикуются уведомления об отключениях 
- 🗂️ **Выбор Telegram-чата** для поиска уведомлений.
- 🔎 **Выбор улицы** для получения информации об отключениях только по выбранной улице.
- 📢 **Уведомления о событиях** на основе заданных чата и улицы.
- ✅ **Управление подпиской** - отключение / включение уведомлений.
- ℹ️ **Получение актуальной информации** о текущей подписке.
- 💾 **Сохранение введённых пользователем данных** в базе для последующего анализа и обработки.
